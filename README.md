# Omni Desk

AI question-and-answer app.

Made by **Pedro** with Claude.

- Play (Claude Artifact): https://claude.ai/artifact/VBSoc9wNXNaXUaaxB2WEgL
- Source: `index.html` (the page), `vendor/` (marked, DOMPurify, highlight.js from npm), `fonts/` (self-hosted woff2 from @fontsource)
- Works only inside Claude (it uses `window.claude`). Opened elsewhere it shows a friendly "open it in Claude" screen.
- To republish: publish `index.html` with `vendor/*.js` and `fonts/*.woff2` as supporting files to the same artifact URL.
